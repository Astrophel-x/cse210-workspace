# Version Control - Articulate

## What is version control and why is it important?

### Version Control Meaning

Version control refers to the idea of having a system that keeps track of what changes are made at what time and by whom in a project of some kind, often but not limited to one being worked on by multiple people. 

### Benefit of Version Control

One benefit is that it allows any earlier version to be recovered at any time. If something gets altered that breaks the project in a major way, the earlier version can be rolled back/recovered. Project history also shows developers many things: what changes were, who made them, at what time, and why those changes were needed. 

### Version Control Application

You have been hired to as a game developer on a game that is halfway completed. You disocver your team is located around the globe - almost everyone is in a different time zone from you, and from each other. You have access to a copy of the entire project as well as the project history. You are able to see what has already been done, the problems that have been identified, and the solutions that have been attempted or implemented. You are able to get caught up to speed without taking the time of anyone else. You identify a potential solution, and propose it before signing off and going to bed. Your teammate is able to review this potential change safely as soon as they begin working. 

### Version Control Command

> git commit -m ""

This command, "commit" is a "snapshot in time". Commits can be organized into "branches" - each "branch" is, or can be, its own line of development. You commit changes to save them, essesntially. It completes whatever change-tracking you have been doing. You have taken you snapshot that is to be added to the project history.
